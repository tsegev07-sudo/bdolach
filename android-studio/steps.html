Building the tablet app in Android Studio

The app בד"ח סופה, built on this computer and installed on the tablets by USB. You need Android Studio (from the software catalog) and these PDFs.

1. Make the project (first time only)

  1. Install Android Studio IDE from the software catalog (and Android Studio tools if it is offered separately).
  2. Open Android Studio → New Project → Phone and Tablet → Empty Views Activity → Next.
  3. Fill in exactly: Name: Bdolach   Package name: com.bdolach.sufa   Language: Java   leave the rest as it is → Finish.
  4. Wait until the bar at the bottom stops working (the first time can take several minutes).
  5. Check that Android Studio can build on this computer: menu Build → Generate App Bundles or APKs → Generate APKs (in older versions: Build → Build Bundle(s) / APK(s) → Build APK(s)).
If this fails with a message about downloading (Gradle, a plugin, "could not resolve"), Android Studio can't get its parts on this network. Ask the software catalog's support how Android Studio is set up to build here (other teams' Android apps are in the catalog, so it is possible). The steps below don't need anything more than this.

2. Put in the app's files

In the panel on the left, switch the view from Android to Project (the drop-down at its top), so the folders match the paths below. Then for each PDF:

  1. Open the PDF → Ctrl+A → Ctrl+C.
  2. In Android Studio, open the file from the table (double-click it) → Ctrl+A → Ctrl+V. This replaces everything in it.
  3. Delete the two lines at the top that came from the PDF (its title and the "Select all" line). The file must start with the code.

If you chose another package name in step 1, change the line package com.bdolach.sufa; near the top of MainActivity.java to match it.

3. Build the app

  1. Build → Generate APKs (as in step 1.5).
  2. When it says the APK is ready, click locate. The app is app-debug.apk in Bdolach\app\build\outputs\apk\debug\. You can rename it to bdolach.apk.

4. Install it on a tablet

  1. Connect the tablet to the computer with a USB cable. On the tablet, choose File transfer when it asks what the USB connection is for.
  2. On the computer, copy the APK into the tablet's Download folder.
  3. On the tablet, open Files (or My Files) → Download → tap the APK → Install. The first time, Android asks to allow installing apps from Files: allow it.
  4. The app בד"ח סופה appears with the other apps. It runs with no network.
Updates: when the content changes, only a new 2-index.html.pdf comes in. Paste it into assets/index.html (step 2), build (step 3) and install over the old app (step 4). Ticks and settings stay.
The app is signed with a key that Android Studio keeps for this Windows user. Build updates as the same user on the same computer; an app built elsewhere won't install over it until the old one is uninstalled from the tablet.
